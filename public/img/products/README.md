# Фото товаров по артикулу

Положите сюда фото с именем по артикулу товара:

- `SF-001.jpg` — главное фото товара SF-001;
- `SF-001_2.jpg`, `SF-001_3.jpg` — дополнительные фото.

Форматы: JPG, PNG, WEBP. Рекомендуемый размер — от 1200×900, не больше 1–2 МБ.

При обновлении сайта фото подключаются к товару автоматически, но только один раз и только если у товара
ещё нет ни одного фото. Фото, загруженные или удалённые вручную в админке, не трогаются.

Используйте только свои фото или фото со свободной лицензией для коммерческого использования
(Unsplash, Pexels, Wikimedia Commons с подходящей лицензией). Источник и лицензию записывайте в `SOURCES.md`.
