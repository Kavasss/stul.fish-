# SHUL.FISH — интернет-магазин рыбы и икры

Магазин копчёной, вяленой и сушёной рыбы и икры с доставкой по Варшаве.
Дизайн повторяет фирменный логотип: чёрный фон, золотые линии и свечение, белые заголовки.

## Возможности

**Витрина**
- Главная, каталог с категориями, поиском и сортировкой, карточка товара с галереей фото
- Корзина и оформление заказа: курьер по Варшаве или самовывоз
- Весовой товар продаётся с шагом 0,5 кг
- Регистрация и вход покупателей, личный кабинет с историей заказов

**Панель управления** (`#/admin`, кнопка ⚙ в шапке)
- **Товары**: создание, редактирование, скрытие с сайта, метки (ХИТ, NEW…), удаление
- **Фото**: загрузка нескольких фото прямо с сайта (сжимаются в браузере), выбор главного, удаление
- **Склад**: приход (с закупочной ценой), расход, списание (обязательно с причиной), инвентаризация
- **Складской учёт**: остатки, стоимость склада по себестоимости и по цене продажи, движение за период, сигнал «мало» и «нет в наличии», выгрузка в CSV для Excel
- **Движения**: полная история операций по каждому товару: кто, когда, сколько
- **Заказы**: смена статусов; при отмене товар автоматически возвращается на склад
- **Сотрудники**: создание менеджеров и администраторов, настройка прав, блокировка, сброс пароля
- **Журнал**: все действия сотрудников

## Запуск

Нужен Node.js 22.13 или новее. Внешних зависимостей нет: база данных — встроенный SQLite.

```bash
npm start
```

Сайт откроется на http://localhost:3000. Данные (база и фото) хранятся в папке `data/`.

При первом запуске создаются администратор (`admin@shul.fish`) и менеджер (`manager@shul.fish`)
со **случайными паролями**. Пароли записываются в файл `data/FIRST-LOGIN.txt`: он доступен только владельцу и не отдаётся через сайт.
Войдите, смените пароли в личном кабинете и удалите этот файл.

Свои пароли можно задать до первого запуска:

```bash
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='надёжный-пароль' MANAGER_PASSWORD='другой-пароль' npm start
```

Каталог стартует пустым — товары добавляются в админке («Товары → Добавить»). Для разработки можно загрузить 16 демо-товаров: `SEED_DEMO=1 npm start` (на пустой базе).

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `TRANSLATE_URL` | Онлайн-переводчик для польских названий и описаний (по умолчанию MyMemory; `off` — только словарь) |
| `TRANSLATE_EMAIL` | E-mail для MyMemory: дневной лимит перевода 50 000 символов вместо 5 000 (необязательно) |
| `DELIVERY_RADIUS_KM` | Радиус курьерской доставки, км (по умолчанию 7) |
| `DELIVERY_PRICE_PER_KM` | Стоимость доставки за каждый начатый км по прямой, zł (по умолчанию 2) |
| `DELIVERY_MIN_FEE` | Минимальная стоимость доставки, zł (по умолчанию 10) |
| `DELIVERY_CENTER` | Центр зоны доставки `широта,долгота` (по умолчанию Bazar Trocka: `52.2765,21.0560`) |
| `GEOCODER_URL` | Геокодер для проверки адреса (по умолчанию Nominatim OpenStreetMap; `off` — не проверять) |
| `PORT` | порт, по умолчанию 3000 |
| `DATA_DIR` | папка с базой и фото |
| `COOKIE_SECURE=1` | cookie только по HTTPS (включите на боевом сайте) |
| `TRUST_PROXY=1` | брать IP клиента из `X-Forwarded-For` (только если сайт стоит за nginx или Caddy) |
| `ALLOWED_HOSTS` | дополнительные домены через запятую, с которых разрешены изменяющие запросы |
| `SHEETS_WEBAPP_URL` | URL веб-приложения Apps Script (связь с Google Таблицей) |
| `SHEETS_SECRET` | секрет для связи с таблицей, не короче 24 символов; такой же вписывается в `Code.gs` |
| `SHEETS_SYNC_INTERVAL` | как часто забирать правки из таблицы, в секундах (по умолчанию 120) |

## Связь с Google Таблицей

Сайт синхронизируется с таблицей «SHUL.FISH — складской учёт» в обе стороны.

| Направление | Что передаётся |
|---|---|
| Сайт → таблица | товары, каждое движение склада (продажи, приходы, списания, возвраты), заказы и смена их статусов — через ~3 секунды после изменения |
| Таблица → сайт | правки цен, себестоимости, названий, описаний, «На сайте»; новые товары с новым артикулом; новые строки на листе «Движения» (например, приход поставки) — раз в 2 минуты или по кнопке |

Настройка (один раз):

1. Придумайте секрет: `node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"`.
2. В таблице: **Расширения → Apps Script**. Вставьте содержимое `google-sheets/Code.gs` и впишите секрет в `SECRET`.
3. **Начать развёртывание → Новое развёртывание → Веб-приложение**. Выполнять от имени: «Я», доступ: «Все».
   Разрешите доступ к таблице и скопируйте URL.
4. На сервере задайте `SHEETS_WEBAPP_URL` и `SHEETS_SECRET` и перезапустите сайт.
5. В админке: раздел **Google Таблица → Полная выгрузка**. Примерные данные в таблице заменятся данными сайта.
   Дальше всё идёт автоматически.

Правила:
- Товар связывается по **артикулу**. Он должен быть уникальным. Если оставить его пустым, сайт сгенерирует артикул сам.
- Проведённая строка движения получает номер в колонке «ID сайта», и второй раз она не проведётся, даже при сбое связи.
  Строка с ⚠ не проведена: исправьте её и очистите ячейку «ID сайта».
- Проведённые строки не редактируйте. Ошибку исправляйте новой строкой «Корректировка».
- Удалённый на сайте товар в таблице помечается «[удалён]» и обратно не создаётся.
- Если одно и то же поле изменили и на сайте, и в таблице между синхронизациями, побеждает таблица.
- Заказы идут только с сайта в таблицу. Статус заказа меняйте на сайте.
- При изменении кода скрипта нужно заново развернуть его: **Развёртывания → Управление → Изменить → Новая версия**.

## Два языка: русский и польский

- Витрина, корзина, оформление заказа, кабинет, ошибки и правовые страницы доступны на русском и польском.
  Язык переключается кнопкой **PL / RU** в шапке и запоминается.
- При первом визите язык берётся из настроек браузера: польский браузер откроет сайт по-польски.
  Ссылки `https://shulfish.pl/?lang=pl` и `?lang=ru` открывают нужный язык сразу.
- У товара есть поля «Название 🇵🇱» и «Описание 🇵🇱» в админке, а в Google Таблице им соответствуют колонки P и Q.
  Если польский текст пуст, показывается русский.
- В заказе сохраняется язык клиента: менеджер видит пометку 🇵🇱 PL.
- Админка — только на русском.
- Тексты интерфейса лежат в `public/js/i18n.js`, правовые тексты обоих языков — в `public/js/legal.js`.
- Кнопка заказа подписана «Zamawiam z obowiązkiem zapłaty». Этого требует ст. 17 польского закона о правах потребителя.

## SEO: Google и соцсети

- У страниц обычные адреса: `/product/3`, `/catalog/caviar`, `/terms`. Старые ссылки вида `/#/product/3` перенаправляются сами.
- Сервер подставляет в каждую страницу свой `<title>`, описание, canonical, hreflang (RU/PL) и Open Graph для превью в соцсетях.
  У товаров есть ещё разметка schema.org `Product`: цена в PLN и наличие.
- `https://shulfish.pl/sitemap.xml` собирается из каталога автоматически, на двух языках. Скрытые товары в неё не попадают.
- `https://shulfish.pl/robots.txt` закрывает от поисковиков админку, кабинет, корзину и API.
- Адрес сайта для ссылок задаётся переменной `SITE_URL` (по умолчанию `https://shulfish.pl`).
- В Google Search Console: **Файлы Sitemap → добавить `sitemap.xml`**.

## Правовые страницы

На сайте есть «Правила магазина», «Политика конфиденциальности» (RODO) и «Политика cookies».
Ссылки на них стоят в подвале сайта. При заказе и регистрации покупатель ставит галочку согласия, и время согласия сохраняется.
Покупатель может сам удалить аккаунт в личном кабинете.

**Перед запуском** впишите реквизиты продавца (название, NIP, REGON, адрес, e-mail, телефон) в начало файла `public/js/legal.js`.
Пока они не заполнены, на правовых страницах показывается предупреждение.
Тексты — шаблон под польское право для продажи продуктов питания. Их стоит показать юристу.
Польская версия документов уже есть. При расхождениях действует она.

## Безопасность

- Покупатели и гости не видят точные остатки, себестоимость, скрытые товары и даты изменений.
  Ошибки при заказе тоже не раскрывают эти данные.
- Пароли хранятся как хэши scrypt, в базе лежат только хэши токенов сессий.
- Вход защищён от перебора: лимит по IP и по e-mail, одинаковое время ответа для любых e-mail.
- Есть ограничения на число регистраций и анонимных заказов.
- Защита от CSRF (проверка Origin и SameSite-cookie), от встраивания админки в чужой сайт (CSP и `X-Frame-Options`), от выхода за пределы папок.
- В CSV-выгрузке экранируются формулы Excel.
- Смена пароля завершает сессии на других устройствах. Блокировка сотрудника выкидывает его сразу.
- Админ видит предупреждение, если у кого-то из сотрудников остался общеизвестный пароль.

## Хостинг

Подходит любой хостинг с Node.js и постоянным диском, например VPS, Render или Railway с подключённым диском.
Папку `data/` нужно сохранять между перезапусками и регулярно копировать: в ней база и фотографии.

### Быстрый запуск на VPS одной командой

Нужен чистый VPS с Ubuntu 22.04/24.04 или Debian 12 и root-доступом по SSH. Подключитесь к нему и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/Kavasss/stul.fish-/claude/zen-wright-u8psjn/deploy/install.sh | bash
```

Скрипт `deploy/install.sh` делает всё сам:
- ставит Node.js 22 и Caddy;
- запускает сайт как службу с автоперезапуском;
- получает HTTPS-сертификат для shulfish.pl;
- включает файрвол и ежедневные резервные копии в `/var/backups/shulfish`;
- проверяет, что DNS домена указывает на этот сервер, и выводит пароли для первого входа.

Повторный запуск обновляет код, данные не трогает.
Настройки (включая связь с Google Таблицей) лежат в `/etc/shulfish/shulfish.env`. После правки выполните `systemctl restart shulfish`.
Если репозиторий приватный, передайте адрес с токеном: `REPO=https://<токен>@github.com/Kavasss/stul.fish-.git`.

### Автообновление из GitHub

Если запустить установку с `AUTO_UPDATE=1`, сервер сам раз в 5 минут проверяет GitHub и ставит новую версию:

```bash
curl -fsSL https://raw.githubusercontent.com/Kavasss/stul.fish-/claude/zen-wright-u8psjn/deploy/install.sh | AUTO_UPDATE=1 bash
```

- перед каждым обновлением делается резервная копия базы и фото;
- если после обновления сайт не отвечает, сервер возвращает прошлую версию, а неудачную больше не ставит;
- журнал обновлений: `journalctl -t shulfish-update`; обновить вручную прямо сейчас: `shulfish-update`;
- выключить: та же команда с `AUTO_UPDATE=0`.

Важно: на сервер попадает всё, что отправлено в ветку `claude/zen-wright-u8psjn`. Давайте право записи в репозиторий только тем, кому доверяете.

### Запуск на shulfish.pl вручную

1. В DNS домена создайте A-записи `shulfish.pl` и `www.shulfish.pl`, указывающие на IP сервера.
2. Поставьте [Caddy](https://caddyserver.com). Он сам получит и будет продлевать сертификат HTTPS. Файл `/etc/caddy/Caddyfile`:

   ```
   shulfish.pl {
       reverse_proxy 127.0.0.1:3000
   }
   www.shulfish.pl {
       redir https://shulfish.pl{uri} permanent
   }
   ```

3. Запустите сайт с настройками для боевого режима:

   ```bash
   COOKIE_SECURE=1 TRUST_PROXY=1 ALLOWED_HOSTS=shulfish.pl DATA_DIR=/var/lib/shulfish npm start
   ```

   Чтобы сайт поднимался сам после перезагрузки, оформите его как службу systemd или запустите через pm2.
