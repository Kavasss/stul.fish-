# SHUL.FISH — интернет-магазин рыбы и икры

Магазин копчёной, вяленой и сушёной рыбы и икры с доставкой по Варшаве.
Дизайн повторяет фирменный логотип: чёрный фон, золотые линии и свечение, белые заголовки.

## Возможности

**Витрина**
- Главная, каталог с категориями, поиском и сортировкой, карточка товара с галереей фото
- Корзина и оформление заказа: курьер по Варшаве или самовывоз
- Весовой товар продаётся с шагом 0,5 кг
- Регистрация и вход покупателей, личный кабинет с историей заказов

**Панель управления** (`#/admin`, кнопка ⚙ в шапке)
- **Товары**: создание, редактирование, скрытие с сайта, метки (ХИТ, NEW…), удаление
- **Фото**: загрузка нескольких фото прямо с сайта (сжимаются в браузере), выбор главного, удаление
- **Склад**: приход (с закупочной ценой), расход, списание (обязательно с причиной), инвентаризация
- **Складской учёт**: остатки, стоимость склада по себестоимости и по цене продажи, движение за период, сигнал «мало» и «нет в наличии», выгрузка в CSV для Excel
- **Движения**: полная история операций по каждому товару: кто, когда, сколько
- **Заказы**: смена статусов; при отмене товар автоматически возвращается на склад
- **Сотрудники**: создание менеджеров и администраторов, настройка прав, блокировка, сброс пароля
- **Журнал**: все действия сотрудников

## Роли и права

| Право | Админ | Менеджер (по умолчанию) |
|---|:-:|:-:|
| Редактирование описаний и наличия | ✅ | ✅ |
| Загрузка и удаление фото | ✅ | ✅ |
| Приход / расход / списание | ✅ | ✅ |
| Обработка заказов | ✅ | ✅ |
| Просмотр складского учёта | ✅ | ✅ |
| Создание товаров | ✅ | можно выдать |
| Изменение цен и себестоимости | ✅ | можно выдать |
| Удаление товаров | ✅ | можно выдать |
| Журнал действий | ✅ | можно выдать |
| Управление пользователями | ✅ | ❌ только админ |

Администратор включает и выключает права каждому менеджеру отдельно. Изменения действуют сразу.

## Запуск

Нужен Node.js 22.13 или новее. Внешних зависимостей нет: база данных — встроенный SQLite.

```bash
npm start
```

Сайт откроется на http://localhost:3000. Данные (база и фото) хранятся в папке `data/`.

Учётные записи, которые создаются при первом запуске:

| Роль | E-mail | Пароль |
|---|---|---|
| Администратор | admin@shul.fish | admin12345 |
| Менеджер | manager@shul.fish | manager12345 |

**Сразу смените эти пароли.** Можно задать свои ещё до первого запуска:

```bash
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='надёжный-пароль' MANAGER_PASSWORD='другой-пароль' npm start
```

Переменные окружения: `PORT` (порт, по умолчанию 3000), `DATA_DIR` (папка с данными).

## Хостинг

Подходит любой хостинг с Node.js и постоянным диском, например VPS, Render или Railway с подключённым диском.
Папку `data/` нужно сохранять между перезапусками и регулярно копировать: в ней база и фотографии.
Для HTTPS поставьте перед приложением nginx или Caddy.
